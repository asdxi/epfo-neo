# Project Instructions

Read PRODUCT_BRIEF.md before making product or architecture decisions.

## Non-negotiables

- Build a working product, not a static mockup.
- Use UX4G Design System 3.0.
- Mobile-first and WCAG 2.1 AA.
- Use fictional/synthetic user data only.
- Never use real user PII or real EPFO credentials.
- Never infer why an employment gap exists.
- Do not expose EPFO implementation details unless useful.
- EPF and EPS must remain conceptually separate.
- Never infer salary from PF contribution data.
- Every important financial number must be explainable.
- Distinguish missing, zero, pending, unavailable, transferred and not-applicable states.
- Keep domain/data logic separate from UI.
- Write tests for financial reconciliation logic.

Before implementing, inspect the existing repository and understand its structure.
